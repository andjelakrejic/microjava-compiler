# MicroJava Compiler

A compiler for **MicroJava**, a simplified Java-like language. It translates `.mj` source files into bytecode for the MicroJava Virtual Machine.

Built as the course project for *Compilers 1* (Programski prevodioci 1) at the School of Electrical Engineering, University of Belgrade, 2025/2026.

## Features

The compiler implements all four classic compiler phases:

| Phase | What it does | Tool |
|---|---|---|
| **Lexical analysis** | Splits source code into tokens (keywords, identifiers, constants, operators), skips comments, reports lexical errors with line and column | JFlex |
| **Syntax analysis** | LALR(1) parser that builds an abstract syntax tree, with error recovery so parsing continues after a syntax error | CUP |
| **Semantic analysis** | Type checking and context conditions, using a symbol table with nested scopes | Symbol table library + AST visitor |
| **Code generation** | Generates MicroJava VM bytecode (`.obj` file) | MJ runtime library |

### Supported language constructs

- Global constants and variables (`int`, `char`, `bool`) and one-dimensional arrays
- Global functions with parameters, local variables and return values
- `if`/`else`, `for` loops with `break` and `continue`
- Ternary operator `Condition ? Expr : Expr`
- Arithmetic, relational and logical (`&&`, `||`) expressions
- `read`, `print`, and the built-in functions `ord`, `chr`, `len`
- `map` operation on arrays (see below)

### `map` operation

```
dst = src.map(x => Expr);
```

Iterates through `src` from the first to the last element. In each iteration `x` holds the current element, and the value of `Expr` is stored into the same position of the new array `dst`. `dst` must already be declared, and `x` must be a variable of the same type as the elements of `src`.

### Semantic checks (examples)

- Every name is declared before use and only once per scope
- Type compatibility in assignments, expressions, conditions and function arguments
- `main` exists and is declared as `void main()` with no parameters
- `break`/`continue` used only inside loops
- `return` type matches the function's declared type

Errors are reported with the line number and a descriptive message.

## Project structure

```
spec/        JFlex lexer spec (.flex) and CUP grammar (.cup)
src/         Compiler source code (semantic analyzer, code generator, main class)
test/        Test MicroJava programs
lib/         JFlex, CUP, symbol table and MJ runtime libraries
config/      log4j configuration
build.xml    Ant build script
```

## Build & run

Requirements: Java 8+ and Apache Ant.

```bash
# generate lexer and parser from spec/, then compile
ant compile

# compile a MicroJava program to bytecode
java -cp "bin;lib/*" rs.ac.bg.etf.pp1.Compiler test/program.mj test/program.obj

# run the generated bytecode on the MicroJava VM
java -cp "lib/*" rs.etf.pp1.mj.runtime.Run test/program.obj

# disassemble the bytecode
java -cp "lib/*" rs.etf.pp1.mj.runtime.disasm test/program.obj
```

On Linux/macOS use `:` instead of `;` in the classpath.

## Example

```java
program MapDemo
    int src[], dst[];
    int x;
{
    void main() int i;
    {
        src = new int[4];
        for (i = 0; i < 4; i++) src[i] = i + 1;

        dst = new int[4];
        dst = src.map(x => x * x);

        for (i = 0; i < len(dst); i++) print(dst[i], 3);
    }
}
```

Output:

```
  1  4  9 16
```
